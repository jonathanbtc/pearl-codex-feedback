# Pearl Codex corrections

Found something wrong or out of date on [pearlcodex.com](https://pearlcodex.com)? [Open a correction](https://github.com/jonathanbtc/pearl-codex-feedback/issues/new?template=correction.yml): the page, what looks wrong and, if you have one, a source. Every page's "Report a mistake" link opens the form with the page filled in.

No GitHub account? Use the form at [pearlcodex.com/report/](https://pearlcodex.com/report/).

Corrections are checked against Pearl's source code before they go in. This repository only collects them; the site's source is kept elsewhere.
